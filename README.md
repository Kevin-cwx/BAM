## Description

SAAS which provides marketing and sales departments all necessary information to start a billboard campaign on Curacao. It provides them with a complete overview of all billboards, both Digital and Print. Not limited to only large scale billboards but also any medium sized advertising space.
It displays the billboard's information such as, view count, price, minimum rental period, owner's contact information, and allows the user to book the billboards they want their campaign to run on.

BAM - Billboard Ad Manager

### Dependencies

* Built as a dynamic web application. Will not be converted to a mobile app.
* Intended to be used in a group setting, with one person entering the data on the site as the entire group deliberates on the best option.
